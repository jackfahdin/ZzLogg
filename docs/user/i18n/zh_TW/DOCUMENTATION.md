## 快速入門

您可以從命令列、桌面應用程式選單或檔案關聯啟動 ZzLogg。命令列可傳入一個或多個檔案路徑；未指定檔案時，程式會依工作階段設定嘗試還原上次的工作階段。

首次使用時，請選擇設定、工作階段與程式日誌的儲存位置：使用者資料目錄、程式旁的 `data` 目錄，或自訂絕對路徑。日後可在「設定 → 儲存」中查看及變更。

主視窗分為三個工作區域：

| 區域 | 用途 |
|---|---|
| 上方主檢視區 | 瀏覽原始日誌及其前後文。 |
| 兩個檢視區之間的搜尋列 | 輸入文字或正規表示式並執行搜尋。 |
| 下方篩選檢視區 | 依檔案中的原始順序查看符合條件與已標記的行。 |

搜尋後，符合條件的行會列入篩選檢視區，並在兩個檢視區中顯示紅色圓點。選取結果可定位至原始日誌；右側概覽可顯示符合項目在整個檔案中的分布。

<a name="exploring-log-files"></a>

## 瀏覽與分析日誌

<a name="search-syntax"></a>

### 搜尋語法與標記

正規表示式能依原始順序擷取相關事件。選擇正規表示式模式時，輸入內容會解讀為搜尋模式；選擇固定字串時，則依文字的字面內容搜尋。

例如，要對照連線開啟與關閉事件：

```text
Entering (Open|Close)Connection
```

括號將候選項分組，`|` 表示「其中任意一個」。這樣便於找出只有開啟、沒有對應關閉的事件。若要同時查看連線類型，可使用：

```text
Entering (Open|Close)Connection|Created a .* connection
```

其中 `.*` 符合同一行內任意長度的字元序列。第二個分支仍要求出現 `Created a`，並在後方某處出現一個空格和 `connection`。

#### 邏輯組合

透過搜尋列旁的按鈕啟用邏輯搜尋。每個搜尋模式都必須以英文雙引號括住，再使用下列運算子組合：

| 運算子 | 意義 | 範例 |
|---|---|---|
| `and` | 兩個模式都符合該行。 | `"x" and "y"` |
| `or` | 任意一個模式符合該行。 | `"x" or "y"` |
| `&` | 邏輯 AND，由左至右短路求值。 | `"x" & "y"` |
| <code>&#124;</code> | 邏輯 OR，由左至右短路求值。 | <code>"x" &#124; "y"</code> |
| `not` | 對括號內的運算式取反。 | `not("x")` |

搜尋歷程用於提供自動完成建議。可從搜尋框的快顯選單編輯或清除歷程，並在一般設定中指定項目數量上限。自動完成會遵循搜尋的區分大小寫選項。

#### 符合項目概覽與行標記

右側概覽以紅色短線顯示符合項目，以藍色短線顯示手動標記的行。按一下行左側的圓點，或選取該行後按 `m`，即可切換標記。若要一次標記多行，先選取這些行，再按 `m` 或使用快顯選單。

篩選檢視區預設同時顯示符合條件與已標記的行，也可切換為僅標記或僅符合模式。按 `Ctrl+L` 可跳至指定行。

#### 正規表示式引擎

ZzLogg 使用 Hyperscan 加速正規表示式搜尋。該引擎不支援部分語法，例如前瞻判斷。Hyperscan 無法編譯某個模式時，ZzLogg 會改用以 PCRE 為基礎的 Qt 正規表示式引擎，此時搜尋可能明顯變慢。詳細限制可選閱線上 [Hyperscan 模式參考](https://intel.github.io/hyperscan/dev-reference/compilation.html#pattern-support)。

<a name="opening-files"></a>

### 開啟檔案

您可以透過「檔案 → 開啟」或工具列開啟日誌，也可以從檔案管理員拖入檔案、提供遠端 URL、在命令列傳入路徑，或使用最近使用的檔案與我的最愛。若安裝套件已註冊 `.log` 檔案關聯，也可在檔案管理員中按兩下日誌開啟。

#### 封存與壓縮檔案

支援的封存格式包括 `zip`、`7z` 和 `tar`。ZzLogg 會將封存檔解壓縮至暫存目錄，再顯示檔案選擇對話方塊，供您選擇其中的檔案。

`gzip`、`bzip2`、`xz` 和 `lzma` 格式的單一壓縮檔案會先解壓縮至暫存目錄，然後開啟。程式依檔案內容或副檔名辨識格式。「設定 → 檔案」中可設定解壓縮與確認選項。

#### 遠端 URL

ZzLogg 將遠端檔案下載至暫存目錄，再開啟下載後的副本。

#### 最近使用的檔案

「檔案」選單提供最多五個最近開啟檔案的快速入口。

#### 我的最愛

透過「我的最愛 → 加入我的最愛」或工具列收藏目前檔案。對於不常開啟、容易從最近使用清單中消失的日誌，我的最愛尤其方便。

#### 剪貼簿

將剪貼簿文字貼入 ZzLogg，程式會將它儲存為暫存檔案，以便像日誌一樣瀏覽及搜尋。

#### 切換已開啟檔案

使用「檢視 → 已開啟檔案」，或按 `Ctrl+Shift+O` 開啟檔案切換對話方塊。

<a name="encodings"></a>

### 字元編碼

ZzLogg 會嘗試自動偵測檔案編碼。若偵測不正確，可在「編碼」選單選擇正確編碼，也可在檔案設定中指定預設編碼，取代自動偵測。

<a name="predefined-filters"></a>

### 預先定義的篩選器

可透過「工具」選單將常用模式儲存為預先定義的篩選器。每個篩選器包含顯示名稱、搜尋模式，以及以正規表示式或純文字處理的選項。

透過搜尋列旁的下拉式清單，可將一個或多個預先定義的模式加入搜尋。搜尋框的快顯選單也支援將目前模式儲存為預先定義的篩選器。

<a name="highlighters"></a>

### 醒目提示規則

醒目提示規則為日誌文字上色，便於辨識錯誤或特定類型的事件。規則以集合管理，可透過快顯選單或「工具 → 醒目提示規則」選擇；一個開啟的檔案可以套用多個集合。

每個集合可包含任意數量的規則。每條規則指定正規表示式或純文字模式，以及前景色與背景色。醒目提示規則不支援邏輯搜尋組合。

規則可套用至整個符合的行，也可以只套用至符合的文字。僅突顯符合文字時，若正規表示式包含擷取群組，則突顯擷取的部分。啟用色彩變化後，符合相同模式的不同字串會採用略有差異的色彩。

集合與規則的順序會影響結果：規則由下往上求值，後續符合的規則會覆寫對應色彩。請據此排列優先順序較高的規則。

匯出醒目提示設定時使用 `.conf` 副檔名，即可在其他電腦匯入。每個集合都有唯一 ID；匯入時僅新增尚不存在的集合。

<a name="color-labels"></a>

### 色彩標籤

色彩標籤可為選取的文字快速建立醒目提示規則。預設提供九種標籤，透過快顯選單或 `Ctrl+Shift+1` 至 `Ctrl+Shift+9` 套用。多個字串可共用相同標籤；`Ctrl+D` 會為選取文字套用下一個標籤。

若要移除某段文字的標籤，選取該文字並在快顯選單選擇「無」。`Ctrl+Shift+0` 會清除所有色彩標籤。色彩可在醒目提示設定對話方塊的「色彩標籤」頁籤中調整。

<a name="changing-log-files"></a>

### 查看持續變動的日誌

其他程式持續寫入日誌時，ZzLogg 仍可顯示及搜尋檔案。日誌增長後，顯示內容會更新；啟用「自動重新整理」還可自動更新搜尋結果。

按 `f` 跟隨檔案結尾，效果類似 `tail -f`。檔案附加新行時，結果中可加入新的符合行；檔案遭到覆寫時，原有搜尋結果會清除。

為區分附加與覆寫，ZzLogg 通常會重新計算已建立索引部分的雜湊值。這種方式較可靠，但處理大型檔案或網路共用檔案時可能較慢。「快速修改偵測」僅檢查檔案開頭與結尾，工作量較少，但可能遺漏中間內容的變更。可在「設定 → 檔案」中選擇策略。

跟隨模式需要檔案變更監控。若原生監控與輪詢皆停用，跟隨模式也會停用。

<a name="scratchpad"></a>

### 暫存區

暫存區適合查看日誌中的 Base64 文字，或格式化 XML/JSON。透過快顯選單或 `Ctrl+Z`，可將選取文字傳送至目前的暫存區分頁；透過對應的快顯選單操作或 `Ctrl+Shift+Z`，可取代該分頁的內容。

在暫存區中，`Ctrl+N` 會新增分頁。這些快捷鍵的意義取決於目前取得焦點的視窗。

<a name="settings"></a>

## 設定

<a name="general"></a>

### 一般

#### 搜尋選項

| 選項 | 作用 |
|---|---|
| 延伸正規表示式 | 依正規表示式語法解讀搜尋模式。 |
| 固定字串 | 依字面文字比對，標點不具有特殊意義。 |
| 漸進式快速尋找 | 模式變更時重新執行快速尋找。 |
| 突顯符合文字 | 在主檢視區與篩選檢視區突顯符合部分。 |
| 色彩變化 | 為不同的符合字串使用略有差異的醒目提示色彩。 |
| 搜尋歷程大小 | 限制用於自動完成的歷程模式數量。 |
| 新增或取代模式時搜尋 | 透過快顯選單更新模式後立即搜尋。 |

搜尋類型設定同時適用於篩選搜尋與快速尋找。

#### 工作階段選項

- 載入上次工作階段：還原先前開啟的檔案、檢視設定、行標記與跟隨狀態。
- 載入檔案時跟隨：為新開啟的檔案啟用跟隨模式。
- 最小化至系統匣：關閉主視窗時，讓應用程式保留在系統匣中。透過系統匣選單或「檔案 → 結束」結束程式。macOS 不提供此選項。
- 啟用多個視窗：允許透過「檔案 → 新增視窗」開啟更多主視窗。逐一關閉視窗時，儲存最後關閉視窗的工作階段；透過「檔案 → 結束」離開時，儲存全部視窗以便還原。

#### 語言

可選擇簡體中文、繁體中文或英語。套用語言設定後，介面立即更新，無須重新啟動。

#### 版本檢查

目前建置未設定更新資訊清單 URL，因此版本檢查程式不會連線至發行服務，也不會顯示自動更新通知。

<a name="view"></a>

### 檢視

#### 字型

建議選擇清晰的等寬字型，例如 DejaVu Sans Mono。若自動設定導致文字顯示不佳，可強制啟用字型反鋸齒。在任一日誌檢視區中，按住 `Ctrl` 捲動滑鼠滾輪即可調整字級。

#### 佈景主題與控制項樣式

介面佈景主題可選擇淺色或深色，控制應用程式介面與圖示的外觀。獨立的 Qt 控制項樣式選項決定控制項的繪製方式，可用樣式依平台而異。部分控制項樣式變更需要重新啟動，程式會顯示提示。

#### 高 DPI

目前應用程式僅使用 Qt 6。Qt 通常會自動處理顯示縮放；若縮放效果不正確，可檢查可用的高 DPI 選項，尤其是使用非整數縮放比例時。

#### 行號與其他顯示選項

統一的行號選項同時控制主檢視區與篩選檢視區的行號顯示。

您可以在兩個檢視區中隱藏 ANSI 終端機色彩逸出序列，讓日誌更容易閱讀；此選項可能降低正規表示式搜尋速度。

<a name="file"></a>

### 檔案

#### 檔案變更監控

原生監控透過作業系統通知重新載入已變更的檔案。對於通知不可靠的網路共用或透過 SFTP 掛載的目錄，可啟用輪詢以定期檢查變更。

快速修改偵測僅計算檔案開頭與結尾的雜湊值。它可提高速度，尤其適合大型或遠端檔案，但可能漏掉中間部分的修改。必須辨識這些修改時，應關閉此選項。

捲動超過檔案結尾可啟用跟隨模式。若希望手動控制跟隨，可停用此行為。

#### 編碼

可使用自動偵測，也可為所有新開啟的檔案指定編碼。

#### 封存檔

啟用封存檔解壓縮後，程式會偵測支援的封存與壓縮檔案，並解壓縮至暫存目錄。預設會詢問是否解壓縮；啟用「不需確認即可解壓縮」可略過提示。

#### 檔案下載

預設情況下，HTTPS 下載必須通過憑證驗證。「忽略 SSL 錯誤」可用於採用自我簽署憑證的開發伺服器，但會停用這項驗證。

<a name="storage"></a>

### 儲存

設定、工作階段與程式日誌使用統一的資料目錄。啟動時的位置選擇畫面與「設定 → 儲存」提供相同的三種選擇：

| 位置 | 用途 |
|---|---|
| 使用者資料目錄 | 為目前的作業系統帳戶儲存資料。 |
| 程式目錄（`data`） | 在程式旁儲存資料，需要該位置可寫入。 |
| 自訂目錄 | 以絕對路徑指定可寫入的目錄。 |

頁面會預覽資料路徑，並提供「開啟目錄」按鈕。變更位置後，程式會安排資料移轉，在重新啟動後生效；出現提示時，可選擇立即或稍後重新啟動。

命令列選項 <code>--data-dir &lt;path&gt;</code> 為目前行程指定資料目錄。使用此選項時，介面中的儲存位置由命令列管理。

<a name="advanced-options"></a>

### 進階選項

- 平行搜尋使用多個 CPU 核心進行正規表示式比對，不適用於快速尋找。
- 預設針對 UTF-8 與單位元組編碼最佳化搜尋。若大多數檔案使用其他多位元組編碼，非拉丁編碼搜尋最佳化可能提升效能。
- 搜尋結果快取會在記憶體中儲存符合的行號，重複搜尋時可重用結果，避免重新掃描檔案。
- 診斷日誌可設定詳細程度。疑難排解通常使用 4 或 5 級即可。程式日誌儲存在所選資料目錄的 `logs` 子目錄中；啟用日誌可能降低搜尋速度。
- 目前應用程式不提供當機回報功能。

<a name="keyboard-commands"></a>

## 鍵盤快捷鍵

日誌導覽採用了 `vi` 與 `less` 的操作習慣。下表列出預設按鍵，可在「設定 → 快捷鍵」中自訂動作。部分按鍵取決於目前的檢視區或視窗。

| 按鍵 | 操作 |
|---|---|
| 上/下方向鍵；`j` / `k` | 依方向鍵方向移動選取位置；`j` 向下、`k` 向上。在 `j`/`k` 前輸入數字可移動指定行數。 |
| 左/右方向鍵；`h` / `l` | 水平捲動。 |
| `Ctrl+Up` / `Ctrl+Down` | 垂直捲動。 |
| `^` / `$` | 移至所選行的開頭/結尾。 |
| `Ctrl+Home` | 跳至檔案開頭。 |
| `Shift+G` / `Ctrl+End` | 跳至檔案結尾。 |
| `Ctrl+L` | 開啟跳至指定行的對話方塊。 |
| `'` / `"` | 向前/向後啟動快速尋找。 |
| `n` / `Shift+N` | 向前/向後重複快速尋找。 |
| `*` / `.` | 尋找選取文字的下一個出現位置。 |
| `/` / `,` | 尋找選取文字的上一個出現位置。 |
| `f` | 切換檔案結尾跟隨模式。 |
| `m` | 切換所選行的標記。 |
| `[` / `]` | 跳至上一個/下一個標記。 |
| `+` / `-` | 縮小/放大篩選檢視區。 |
| `v` | 循環切換篩選模式：標記與符合 → 標記 → 符合。 |
| `F5` | 重新載入目前檔案。 |
| `Ctrl+S` | 將焦點移至搜尋框。 |
| `Ctrl+Shift+O` | 開啟檔案切換對話方塊。 |
| `Ctrl+Shift+1`–`Ctrl+Shift+9` | 為選取文字套用色彩標籤。 |
| `Ctrl+D` | 套用下一個色彩標籤。 |
| `Ctrl+Shift+0` | 清除所有色彩標籤。 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 傳送選取文字至暫存區/取代暫存區內容。 |
| 暫存區中的 `Ctrl+N` | 新增暫存區分頁。 |

舊版手冊中的 `[number]g`、`G` 與 `Alt+G` 已不再是目前的預設按鍵。跳至指定行請用 `Ctrl+L`，跳至檔案開頭請用 `Ctrl+Home`；您可在快捷鍵設定中查看或調整自己的按鍵設定。

<a name="command-line-options"></a>

## 命令列選項

在選項後傳入一個或多個檔案路徑；包含空格的路徑需要加上引號。以下以 Windows 執行檔名稱為例，其他平台請使用實際安裝的程式名稱。

```text
ZzLogg.exe "C:\Logs\server.log"
ZzLogg.exe --follow "C:\Logs\server.log"
ZzLogg.exe --data-dir "D:\ZzLoggData" --new-session "C:\Logs\server.log"
ZzLogg.exe --log --debug 2
```

| 選項 | 作用 |
|---|---|
| `-h, --help` | 顯示說明並結束。 |
| `-v, --version` | 顯示版本資訊。 |
| `-m, --multi` | 允許多個程式執行個體同時運作；搭配 `-s` 載入已儲存的工作階段。 |
| `-s, --load-session` | 載入上次工作階段；未指定檔案時的預設行為。 |
| `-n, --new-session` | 不載入上次工作階段；指定檔案時的預設行為。 |
| `-l, --log` | 將程式診斷輸出寫入日誌檔案。 |
| `-f, --follow` | 跟隨啟動時開啟的檔案。 |
| <code>-d, --debug &lt;debug_level&gt;</code> | 依數值增加診斷詳細程度，例如 `-d 2`；目前語法不使用 `-dddd` 這類重複字母。 |
| <code>--data-dir &lt;path&gt;</code> | 為目前行程使用指定的絕對資料目錄。 |
| <code>--window-width &lt;width&gt;</code> | 設定新視窗寬度。 |
| <code>--window-height &lt;height&gt;</code> | 設定新視窗高度。 |

主控台模式的參數剖析器另支援 <code>-e, --pattern &lt;pattern&gt;</code> 來指定搜尋模式；圖形應用程式的參數剖析器不提供此選項。請對實際執行的程式使用 `--help` 查看可用選項。
