# 受保护安装事务 3C：升级执行与恢复设计

## 1. 已确认的方向

继承 `2026-09-15-installer-only-update-design.md` 第 3、5、6 节与 `2026-09-16-installer-handoff-design.md` 的交接边界。3B.4 已交付：可取消的退出准备/提交、同安装目录实例协调与全部启动入口保护、能力门禁恒闭的"退出并更新"界面、目录预留跨主程序退出延续、ZzLoggUpdate.exe 正式部署。

本阶段采用**NSIS 受限升级入口 + 载荷内嵌原生事务引擎**：

- NSIS 升级段只做提权入口该做的事：UAC、目标独立核对、把安装包载荷中的事务引擎提取到受保护暂存并以管理员身份运行。NSIS 脚本不承载事务逻辑。
- 事务引擎是编译进安装包载荷的原生可执行文件（静态 CRT、无 Qt，与 ZzLoggUpdate.exe 共用 src/updater 源闭包与加密依赖），负责暂存验证、备份、文件与登记替换、持久日志和幂等恢复。引擎只从安装包载荷经受保护暂存运行，绝不从用户可写缓存目录加载。
- 协调者保持原用户普通权限：启动安装器、持有目录预留、等待交接消息、安装完成后重启新版 GUI。禁止管理员身份直接启动 GUI。

本文是设计，不表示真实安装已启用。生产签名、正式发布身份与隔离 Windows 环境验收完成前，生产入口保持关闭；本机不弹真实 UAC、不写真实 HKLM、不修改真实安装目录。

## 2. 组件与信任边界

| 组件 | 权限 | 职责 | 边界 |
| --- | --- | --- | --- |
| 协调者（ZzLoggUpdate.exe 子进程） | 原用户普通权限 | 持有目录预留观察句柄；启动已验证安装器；驱动交接协议；重启新版 | 不信任任何客户端传入的授权；提权父进程时只报告 ManualRestartRequired |
| NSIS 升级段（ZzLogg.nsi 受限模式） | 管理员（UAC） | 独立核对登记/标记/路径；创建受保护暂存；提取并启动事务引擎；联动卸载清单 | 受限升级模式不解析任意参数，不允许 `/D=` 切换目标，不重选关联/快捷方式 |
| 事务引擎（载荷内嵌原生 exe） | 管理员（由 NSIS 段启动） | 暂存验证、备份、文件/登记替换、持久日志、幂等恢复、启动确认配合 | 只操作核实的原安装目录与受保护暂存/备份；作为交接协议客户端对协调者完成 Hello→AwaitingAppExit→Complete |
| 生产门禁 | — | 缺生产签名/发布身份/发布者策略时关闭执行 | 本阶段不改变门禁；测试替身不进入生产入口 |

高权限代码不信任客户端传入的目标路径、文件列表或"已校验"标记：NSIS 段与引擎各自独立核对登记、发布身份、原安装路径与文件系统边界；所有路径检查覆盖实际文件操作（操作期以句柄身份复核），防止检查后替换。

## 3. 升级触发链

1. 3B.4 链路完成保存、同目录预留与握手；协调者持有预留观察句柄，主程序提交退出并真实退出。
2. 协调者从 3B.2 的执行前验证取得安装包（签名信封、渠道、反回放、发布者策略、大小/SHA-256 均通过且文件租约保持稳定），以 `ShellExecuteEx` + `runas` 启动安装器，唯一参数为受限升级开关与一次性随机事务定位名。启动失败、UAC 取消、握手超时均失败关闭，恢复原应用可用状态。
3. 安装器升级段核对通过后在受保护位置建立事务目录，提取载荷内嵌引擎并启动；引擎作为管道客户端连接协调者完成 Hello；引擎独立复核目标后发送 AwaitingAppExit；协调者确认真实进程身份与凭据后才提交退出（既有 3B.3/3B.4 语义不变）。
4. 协议升级：协调者发出 CommitExit 后等待应用**真实进程退出**（既有语义：窗口关闭不算进程结束），随后向引擎发送新增的 Proceed 消息；引擎在收到 Proceed 前不得修改安装目录的任何文件。3B 既有消息集没有"应用已退出"信号，这是本阶段对线路协议的显式扩展（版本号同步提升，旧对端拒绝）。
5. 引擎执行事务；完成后发送 Complete；协调者以原用户身份重启新版 GUI 并等待启动确认；启动确认前备份保留；确认失败进入第 6、7 节的授权恢复路径。
6. 协调者丢失或崩溃时，目录预留随其句柄消失；残留事务日志的恢复见第 6 节，不自动进行。

生产开放时，由应用侧把经 3B.2 验证的安装包路径与选择上下文放入交接请求（3B.4 的会话 Request 扩展）；本阶段该路径仅供测试 fixture 使用，生产构造仍无会话工厂。

事务凭据（事务 ID、单次令牌）由协调者写入当前用户私有的临时凭据文件（随机名、ACL 仅限当前用户），受限开关只携带定位名；引擎读取后立即删除该文件。令牌不进入命令行或普通日志；管道 DACL 仍限定登录 SID，拒绝远程客户端。安装器/引擎侧的管道客户端身份仍按真实进程句柄、创建时间、用户/登录会话与提升状态验证。

## 4. NSIS 受限升级入口

- 新增受限模式开关（如 `/ZzLoggUpgrade=<定位名>`）。该模式下：跳过 Welcome/Directory/Components 交互页；禁止 `/D=` 生效（升级不允许切换目标）；不重新选择文件关联与快捷方式（保留既有选择）；全程静默但有界日志写入受保护事务目录。
- 独立核对（失败即拒绝，不修改任何目标）：64 位视图读取 `HKLM\...\Uninstall\ZzLogg` 的 `InstallLocation` 与 `UpdateIdentitySchema`；目标路径安全（本地盘符绝对路径、逐级拒绝 reparse point）；`.zzlogg-install-root` 标记与落地清单一致性；目录身份（卷序列号 + 文件 ID）与登记路径一致。以上与 3A 探测语义同构，但在安装器内独立实现，不调用主程序代码。
- 核对通过后：在受保护根（第 5 节）创建事务专属目录（独占创建、管理员/系统写、用户读），提取载荷内嵌的引擎与新版文件集清单，启动引擎并等待其退出码；引擎失败时按日志决定是否已自动恢复，未恢复则保留现场并报告人工/授权恢复入口。
- 正常交互安装模式（新装/手动运行）行为不变；升级段不影响既有安装/卸载段的登记契约与卸载清单生成顺序（既有契约测试继续承重）。

## 5. 受保护暂存、备份与持久日志

- 受保护根：`%ProgramData%\ZzLogg\UpdateTransactions\<事务 ID 十六进制>\`，管理员/系统可写、已验证用户只读；每事务独立目录，独占创建，拒绝重解析与网络路径。不使用用户可写缓存目录承载高权限代码或恢复指令。
- 目录内：`staging\`（载荷提取与验证）、`backup\`（被替换/删除的受管理文件与登记旧值）、`journal.log`（追加式持久记录）。
- journal 在每次文件/登记操作**之前**落盘并刷写：操作类型、规范路径、备份位置、预期与实际的尺寸/SHA-256、登记旧值。恢复只依据 journal 逆序幂等执行；每条记录可独立重放（已完成的操作重放为无操作）。不把多个文件移动声称为整体原子操作。
- 目标卷空间预检：暂存 + 备份 + 日志所需总量不足时拒绝开始，不进入部分替换。

## 6. 文件集与登记事务

- 引导版本起，安装段增写机器可读落地清单 `.zzlogg-files.manifest`（每受管理文件的相对路径、尺寸、SHA-256，含 Uninstall.exe 与标记文件之外的全部安装器拥有文件）；`UpdateIdentitySchema` 升为 2。schema=1 的安装按 Legacy 处理：不自动升级，提示手动安装一次新引导版本。不通过扫描目录或猜测旧文件列表决定删除集。
- 改动集合 = 旧清单与新清单的差分：新增/变更文件从 staging 复制；删除集 = 旧清单减去新清单；未知文件（不在旧清单中）一律不删除；已修改的受管理文件（实际哈希 ≠ 旧清单）或用户数据与新载荷冲突时停止并报告，不覆盖。
- 保护用户配置、收藏、会话、存储定位文件与所有已知数据根；不递归清空安装目录；数据目录与安装位置不相互推断。
- 登记与文件属于同一事务：DisplayVersion 等卸载项值的更新记录旧值进 journal，恢复时一并还原；`.zzlogg-install-root` 标记与落地清单随文件集更新，失败时随备份还原。
- 普通失败（复制/哈希/登记任一步失败）自动逆序恢复本次改动；进程或系统中断后，journal 残留保留备份，下一次恢复需要明确 UAC 授权（经 NSIS 受限入口的恢复模式），禁止承诺断电时无提示回滚。

## 7. 普通权限重启与启动确认

- 事务完成（Complete）后，协调者以原用户身份启动 `<安装根>\ZzLogg.exe`；启动前复核新主程序路径仍位于已登记安装目录且标记/清单一致。
- 数据定位参数经受限通道传递：bootstrap 映射升级到版本 3，增加可选的有界数据目录字段（绝对路径、长度上限、无控制字符）；只传递 `--data-dir` 等价信息，不透传任意命令行。旧版本映射拒绝。
- 启动确认：协调者等待有界窗口，要求新进程存活且其按目录作用域隔离的单实例端点出现（复用 3B.4 的目录隔离实例名机制，不为健康检查新增生产 CLI 开关）。安装完成不等于启动健康；确认失败时报告并进入第 6 节的授权恢复路径；新版仍在运行时不得盲目覆盖回退，数据不做整目录回滚。
- 父进程原本已提权时不自动重启，返回 ManualRestartRequired 提示手动启动（沿用既有语义）。

## 8. 本阶段交付与验收边界

- 交付：事务引擎（暂存验证/备份/替换/登记/日志/幂等恢复）与其原生测试；NSIS 受限升级入口与静态契约测试；协调者生产链路（启动安装器、凭据文件、重启与启动确认）；bootstrap v3；文档更新。
- 本机不做：真实 UAC、真实 HKLM 写入、真实安装目录修改、真实 NSIS 运行。引擎逻辑在临时目录与注入的注册表读写器下用真实子进程测试；NSIS 段以静态契约测试验收；协调者链路用真实测试安装器/引擎 fixture 验收，fixture 只编译进测试目标。
- 生产门禁不变：缺生产证书策略/正式发布身份时执行入口保持关闭；本阶段不开放"退出并更新"的生产可见性。
- 隔离 Windows 环境真实验收（旧版升级、Program Files、UAC 取消、另一管理员账号、多实例、文件占用、空间不足、篡改/路径替换、进程终止、重启恢复、登记与用户数据保持、新版失败后恢复）是阶段 4 上线的前置条件，不在本机验收范围内，也不能以源码契约测试代替。
