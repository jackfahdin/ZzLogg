# 界面与错误提示翻译补全

## 范围

用户要求检查整个程序的翻译遗漏，并将“拷贝”统一为“复制”。检查应用源码、UI 表单、三语 TS 目录，以及向界面传播的解析器、存储和更新错误。开发日志、命令行诊断、程序标识和用户自己的文本不作为界面文案改写。

## 已处理

- 补齐缺失、空白和标记为 unfinished 的有效译文，合并重复上下文和消息，修正已发现的误译；简体中文统一使用“复制”，繁体中文使用“複製”。
- 为跳转行、标签页重命名、快捷键编辑、状态栏右键菜单、新建高亮规则、语法菜单、索引失败及问题报告确认框接入翻译。
- 逻辑表达式错误采用可翻译的诊断；保留无效表达式状态，在显示时翻译，切换语言不会重新搜索或清空输入。
- Qt 正则错误保留具体原因。Qt 6.11.1 的繁体中文目录比简体中文目录少 103 条 QRegularExpression 诊断；应用目录补齐，并用 qtregextranslationkeys.h 保留 lupdate 提取键。升级 Qt 时可重新核对这组补充键。
- 存储校验、定位和迁移错误接入翻译，保留路径与具体原因；下载错误按错误类型显示本地化说明。
- 界面初始化和更新组件的原始异常保留到日志，界面显示本地化说明。Windows 便携更新助手由主程序传入翻译后的弹窗标题和摘要，保留原来的七参数调用兼容性。
